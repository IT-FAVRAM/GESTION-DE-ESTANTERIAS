# Inventory Audit Contract

Required fields for every inventory history event generated by backend operations:

- `barcode` (string)
- `orderId` (string)
- `action` (string)
- `timestamp` (ISO string)
- `uid` (string, must match authenticated user)
- `role` (string, must match effective role)
- `user` (string, email or display identifier)
- `opId` (string, operation correlation id)
- `source` (string, expected: `inventoryOperate`)

Operational requirement:

- Inventory write flows must generate history from backend callable path.
- Client-side writes must not be trusted as audit source of truth.
